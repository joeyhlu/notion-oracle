Notion Oracle

Bring your own API key. Keys are stored only in this browser profile (chrome.storage.local) and are sent only to the provider you choose and to Notion.

1. AI provider

Create one at console.anthropic.com. This is separate from a Claude.ai subscription and is billed per use.
Create one at platform.openai.com. This is separate from a ChatGPT subscription.

2. Notion integration optional

Without this, Oracle can still read and edit the page you have open. With it, Oracle can search your workspace, create pages, and add entries to databases and calendars.

  1. Open notion.so/profile/integrations and create an internal integration with read, update and insert content capabilities.
  2. Copy its Internal Integration Secret below.
  3. In Notion, open each page or database Oracle should reach, click ••• → Connections → add your integration. (Sharing a top-level page shares everything under it.)

3. Custom instructions optional

Using Oracle

  • Open any Notion page and press Ctrl+Shift+Space (⌘+Shift+Space on Mac), click the toolbar icon, or the ◎ button at the bottom right.
  • Try: “Summarize this page”, “Turn the meeting notes into action items”, “Rewrite the selection more formally”, “Add dentist on Sept 12 at 2pm to my calendar”, “Create a page under this one called Q4 plan with an outline”.
  • Change the shortcut at chrome://extensions/shortcuts.
